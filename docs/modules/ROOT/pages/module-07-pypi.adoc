== Enterprise PyPI patterns

Field delivery usually puts an *enterprise artifact manager* (Nexus or Artifactory) between developers and `packages.redhat.com`—the same idea as Maven in Module 2, with *pip* indexes instead of Maven repositories.

[cols="1,2,2",options="header"]
|===
|Pattern |pip index |When you use it

|*Direct*
|`{python-validated-simple-url}` (and Remediated when available)
|Laptop PoC or CI with Lightwell membership

|*Proxied (enterprise)*
|Internal Nexus / Artifactory PyPI repos that remote or host the same tiers
|Nearly all customer PoVs; workshop default via `charts/components/lightwell-repo`

|*Seeded (RHDP)*
|Same Nexus *repository names*; wheels uploaded by Job `lightwell-repo-seed`
|Deterministic labs when live *Lightwell Network (LWN)* membership is unavailable
|===

Canonical remotes (document even when mirroring):

* Validated: `{python-validated-url}` (simple: `{python-validated-simple-url}`)

Workshop Nexus repository ids:

* `lightwell-python-validated` — Module 7 default
* `lightwell-python-remediated` — Module 8 (may be gated off if live Remediated PyPI is unavailable)

== Exercise 3 — Validated install from the seeded app

[source,bash,role=execute]
----
: "${STUDENT_PYTHON_REPO_URL:=$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_python_repo_url}')}"

rm -rf /tmp/fastapi-lw-poc
# Student app repos are public — anonymous clone; credentials are for push / seed only
git clone "${STUDENT_PYTHON_REPO_URL}" /tmp/fastapi-lw-poc
cd /tmp/fastapi-lw-poc

ls -la requirements.txt pip.conf
----

Prefer the cluster ConfigMap `pip.conf` (correct host for this claim). Install into a writable virtual environment under `/tmp`:

[source,bash,role=execute]
----
export LIGHTWELL_NEXUS_URL="https://$(oc -n lightwell-repo get route nexus -o jsonpath='{.spec.host}')"
oc -n lightwell-repo extract configmap/lightwell-pip-settings \
  --keys=pip.conf --to=/tmp/fastapi-lw-poc --confirm

python3 -m venv /tmp/fastapi-venv
source /tmp/fastapi-venv/bin/activate

PIP_CONFIG_FILE=/tmp/fastapi-lw-poc/pip.conf \
  python3 -m pip install -r requirements.txt \
  > /tmp/pip-validated-seed.log 2>&1

grep -E 'httpx|lightwell-python-validated|Successfully installed|ERROR' \
  /tmp/pip-validated-seed.log | tail -40
----

Expected:

* `httpx==0.27.2` resolves from Nexus `lightwell-python-validated` (seeded wheel in RHDP)
* FastAPI / uvicorn may come from the `extra-index-url` (public PyPI)—same idea as Maven Central fallback in Module 2
* Install completes without errors

Quick package check:

[source,bash,role=execute]
----
python3 -m pip show httpx | grep -E '^(Name|Version|Location):'
deactivate
----

== Exercise 4 — Delete the seeded app repo

The Software Template *creates* a new Gitea repository; it does not force-push over an existing one. Delete only the **app** repo (keep GitOps).

In the *Gitea UI*:

. Open organization *`lw-@@LW_USER@@`* → repository *`fastapi-lw-poc`*
. *Settings* → *Danger Zone* → *Delete This Repository*
. Type the repository name to confirm and delete

Or from the Showroom terminal:

[source,bash,role=execute]
----
: "${GITEA_URL:=$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.gitea_url}')}"
: "${GITEA_ORG:=$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_gitea_org}')}"
export STUDENT_USER='@@LW_USER@@'
: "${STUDENT_PASS:=$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_password}')}"
: "${STUDENT_PYTHON_REPO_NAME:=$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_python_repo_name}')}"

curl -sk -o /dev/null -w "%{http_code}\n" -u "${STUDENT_USER}:${STUDENT_PASS}" \
  -X DELETE "${GITEA_URL}/api/v1/repos/${GITEA_ORG}/${STUDENT_PYTHON_REPO_NAME}"
----

Expect HTTP `204`. A `404` means the repo is already gone—continue.
