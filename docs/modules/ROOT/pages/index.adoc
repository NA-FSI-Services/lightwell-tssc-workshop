= Lightwell Software Supply Chain Security Workshop
:toc:

Welcome. This RHDP workshop teaches the same Lightwell Network integration patterns used in field proof-of-value delivery—paired with Red Hat Trusted Software Supply Chain controls on OpenShift.

== What you will learn

. *Validated* vs *Remediated* repository tiers (exact-version `.rhlw-*` pins)
. Enterprise Maven consumption via an artifact manager proxy
. OSV-driven triage and source comparison
. SBOM analysis with Trusted Profile Analyzer (optional RHDA on a laptop)
. Pipeline signing (RHTAS), policy gates (RHACS), and GitOps promotion
