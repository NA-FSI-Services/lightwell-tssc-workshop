= Lightwell Software Supply Chain Security Workshop
:toc:

Welcome. This *Red Hat Demo Platform (RHDP)* workshop teaches the same *Lightwell Network (LWN)* integration patterns used in field *proof-of-value (PoV)* delivery—paired with Red Hat *Trusted Software Supply Chain (TSSC)* controls on OpenShift.

== What you will learn

. *Validated* vs *Remediated* repository tiers for **Java (Maven)** and **Python (PyPI)** (exact-version `.rhlw-*` pins)
. Enterprise Maven and pip consumption via an artifact manager proxy (not Satellite)
. *Red Hat Developer Hub (RHDH)* Software Template scaffold into in-cluster Gitea (Java and Python)
. *Open Source Vulnerabilities (OSV)*–driven triage and source comparison (`RHLW-*` / workshop `LW-DEMO-*`)
. *Software Bill of Materials (SBOM)* / *Vulnerability Exploitability eXchange (VEX)* analysis with *Red Hat Trusted Profile Analyzer (RHTPA)* (optional *Red Hat Dependency Analytics (RHDA)* on a laptop)
. Pipeline signing (*Red Hat Trusted Artifact Signer (RHTAS)*), policy gates (*Red Hat Advanced Cluster Security (RHACS)*), and GitOps promotion
