= Module 1: Your First Lab Page
:navtitle: Module 1: Your First Lab Page

This page is a working example of a Showroom lab module.
It demonstrates the AsciiDoc patterns you'll use when writing your own content.
Replace this page with your actual lab instructions.

== Headings Structure

Lab pages typically use this structure:

* `= Page Title` -- the page heading (one per page)
* `== Section` -- major steps or topics
* `=== Subsection` -- detailed steps within a section

== Attribute Substitution

Use `subs="attributes"` on code blocks to inject runtime variables.
These values come from `content/antora.yml` during local preview, and from `user_data` at deploy time.

[source,bash,subs="attributes",role="execute"]
----
ssh {ssh_user}@bastion.{guid}.example.com
----

You can also use attributes inline: your environment GUID is *{guid}* and the console is at {openshift_console_url}.

== Admonitions

[NOTE]
====
Use `NOTE` for supplementary information that helps but isn't essential.
====

[TIP]
====
Use `TIP` for best practices or shortcuts.
====

[IMPORTANT]
====
Use `IMPORTANT` for information the reader must not miss.
====

[WARNING]
====
Use `WARNING` for actions that could cause data loss or break the environment.
====

== Images

Place images in `content/modules/ROOT/images/` and reference them:

[source,asciidoc]
----
image::showroom-preview.png[Alt text,width=600]
----

Here's that example rendered (a placeholder image -- swap it for your own screenshots):

image::showroom-preview.png[Showroom local preview placeholder,width=600]

To make an image expandable (click to zoom), add the `.expand` role.
Use `.fullscreen` instead to open the image in true browser fullscreen:

[source,asciidoc]
----
[.expand]
image::showroom-preview.png[Alt text,width=600]

[.fullscreen]
image::showroom-preview.png[Alt text,width=600]
----

== Execute in Terminal

Add `role="execute"` to a code block to give readers a clickable button that sends the command directly to their terminal:

[source,bash,role="execute"]
----
echo "Hello from Showroom!"
----

Without the role, a code block only gets a copy button:

[source,bash]
----
echo "This block only has copy"
----

== Callouts

Use callout markers to annotate specific lines in a code block.
The comment syntax must match the source language:

[source,text]
----
line of code // <1>
line of code # <2>
line of code ;; <3>
line of code <!--4-->
----
<1> A callout behind a line comment for C-style languages.
<2> A callout behind a line comment for Ruby, Python, Perl, etc.
<3> A callout behind a line comment for Clojure.
<4> A callout behind a line comment for XML or SGML languages like HTML.

== Tabs

Show alternative instructions (e.g. different tools or operating systems) using tab blocks:

[tabs]
====
CLI::
+
[source,bash,role="execute"]
----
oc get pods
----

Web Console::
+
Navigate to menu:Workloads[Pods] in the OpenShift console.
====

== Mermaid Diagrams

Embed diagrams directly in your content.
Add `.expand` to click-zoom within the page, or `.fullscreen` to open in true browser fullscreen:

.Click to expand within page
[mermaid.expand,width=100%]
....
flowchart LR
    A[Author Content] --> B[Push to Git]
    B --> C[Showroom Builds]
    C --> D[Participant Views Lab]
....

.Click to open fullscreen
[mermaid.fullscreen,width=100%]
....
flowchart LR
    A[Author Content] --> B[Push to Git]
    B --> C[Showroom Builds]
    C --> D[Participant Views Lab]
....
