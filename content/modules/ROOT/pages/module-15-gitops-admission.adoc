= 6.1 GitOps + admission
:source-highlighter: rouge
:toc:
:toclevels: 2

Promote the signed app digest into *stage* via GitOps, then turn on portable admission so unsigned images cannot run. You edit *one* file: `admission/trust-policy.yaml` (`kind: TrustPolicy`) on the *stage* Gitea remote. A CronJob renders namespaced `ImagePolicy` on `lw-poc-staging` *and* `lw-poc-prod`. Do not apply `ClusterImagePolicy`. Do not use RHACS Trusted image signers for this gate (public keys only; Track 5.1 is keyless).

Prod GitOps is a *second remote* — leave it for xref:module-16-prod-gitops.adoc[6.2]. `app-operate` NetworkPolicy on staging stays *open* (that is not the xref:module-10-build-networkpolicy.adoc[4.3] build-egress Check).

== Learning objectives

By the end of this module, you will be able to:

* `oc tag` the signed image from `lw-poc-build` into `lw-poc-staging` and commit digest + `replicas: 1` to the *stage* GitOps remote
* Fill TrustPolicy so no `REPLACE_ME_*` remains and `enforce: true`
* Show unsigned deny as a *pull* failure (ImagePullBackOff), not `oc apply` stderr
* Leave the prod remote and prod Argo Application untouched

== Delivery note

*Customers* promote a signed digest with GitOps and admit only that identity. *You* commit to Gitea and fill TrustPolicy; the cluster renders `ImagePolicy`. A production VM is the *same digest* on a different runtime (bootc / Satellite) — callout only, no VM in this claim.

== Your change: tag, stage GitOps, TrustPolicy

. Tag the signed image into staging (not prod):

[source,bash,role=execute]
----
BUILD_NS="$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_build_namespace}')"
PROMOTE_NS="$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_promote_namespace}')"
oc tag "${BUILD_NS}/spring-boot-lw-poc:latest" "${PROMOTE_NS}/spring-boot-lw-poc:latest"
oc -n "${PROMOTE_NS}" get istag spring-boot-lw-poc:latest \
  -o jsonpath='{.image.metadata.name}{"\n"}'
----

Keep the `sha256:` prefix. That digest must match Track 5.1.

. Clone the *stage* GitOps remote (`student_gitops_repo_url`). Set `image.digest` to that digest and `replicas: 1`. Commit and push. Do not edit the prod remote. Follow `PROMOTE.md` in that repo if you need the field names.

. Wait until Argo Application `lw-poc-staging` is Synced / Healthy (hard-refresh if it still shows `replicas: 0`).

// VISUAL: https://github.com/NA-FSI-Services/lightwell-tssc-workshop/issues/56
image::FIXME-argo-stage-healthy-prod-seed.png[Argo Application lw-poc-staging Healthy; prod still on seed digest,width=700,link=self,window=blank]

. Edit `admission/trust-policy.yaml` on the *same* stage remote. Do not change `apiVersion` / `kind`. Set `enforce: true`. Replace every `REPLACE_ME_*` with live values: issuer `https://kubernetes.default.svc` (or userinfo `oidc_issuer_hint`), subject the pipeline SA URI from 5.1, digest the signed `sha256:…`, scopes the internal ImageStream repo staging (and prod) actually pull — discover with `oc get is`, do not invent a public registry. Do not paste Fulcio / Rekor PEMs (the CronJob injects those).

CronJob `trust-policy-apply` in `tssc-admission` polls about every two minutes. Pass when `ImagePolicy` exists in both `lw-poc-staging` and `lw-poc-prod` (name from userinfo `policy_name`).

== Check: unsigned deny; stage Healthy

Native `ImagePolicy` is CRI-O `policy.json`: `oc apply` of an unsigned Deployment can *succeed*; the pod fails at *pull*. Kyverno fallback (if the claim uses it) denies at admission instead — still look at the pod / events.

The gate only covers `spec.scopes`. Tag an *unsigned* digest onto the *same* ImageStream and deploy that tag. Do not point GitOps `image.digest` at it (that would flap the Healthy Check).

[source,bash,role=execute]
----
BUILD_NS="$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_build_namespace}')"
PROMOTE_NS="$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_promote_namespace}')"
ARGO="$(oc -n gitea get configmap demo-userinfo-gitea -o jsonpath='{.data.student_argocd_app}')"
# Unsigned digest, in-scope name:
oc tag "${BUILD_NS}/openjdk-21-builder:latest" "${PROMOTE_NS}/spring-boot-lw-poc:unsigned"
oc -n "${PROMOTE_NS}" create deployment unsigned-deny-test \
  --image="image-registry.openshift-image-registry.svc:5000/${PROMOTE_NS}/spring-boot-lw-poc:unsigned"
oc -n "${PROMOTE_NS}" rollout status deploy/unsigned-deny-test --timeout=30s || true
oc -n "${PROMOTE_NS}" get pods -l app=unsigned-deny-test
oc -n "${PROMOTE_NS}" get events --field-selector reason=Failed --sort-by=.lastTimestamp | tail -10
oc -n "${PROMOTE_NS}" delete deployment unsigned-deny-test
oc -n openshift-gitops get applications.argoproj.io "${ARGO}" \
  -o custom-columns=NAME:.metadata.name,SYNC:.status.sync.status,HEALTH:.status.health.status
oc -n "${PROMOTE_NS}" get imagepolicy
oc -n lw-poc-prod get imagepolicy
----

Pass when: TrustPolicy has no `REPLACE_ME` and `enforce: true`; ImagePolicy is live on staging *and* prod; the `:unsigned` pod is ImagePullBackOff (or signature error); `lw-poc-staging` stays Healthy on the signed digest. Do not retarget prod Argo at the stage remote.

== Callouts (not Checks)

== Key takeaways

* One learner file; the live API is namespaced `ImagePolicy` (not `ClusterImagePolicy`).
* Promotion to prod is a commit to a *second* remote (6.2).
